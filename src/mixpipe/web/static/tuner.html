Standard

—

Start the microphone, then play one string.

The tuner finds which string you play. If a string is far off (new strings) or it picks the wrong one, tap the string to lock it; tap again to go back to automatic. ▶ plays the note to tune by ear. Once a string holds in tune it locks in with a chime; play it again to re-check.

Through an amp: chorus, vibrato and delay really do move the pitch, so switch them off for the steadiest needle (or tune before them, as a pedal tuner would). Distortion is fine.
